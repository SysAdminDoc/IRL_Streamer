# IRL Streamer identity

The mark combines a camera aperture, broadcast signal, and forward route to represent mobile live production.

## Files

- `irl-streamer-mark-v2.png`: transparent project mark.
- `irl-streamer-app-icon-v2.png`: 1024 × 1024 launcher/store preview on the app background.
- `irl-streamer-mark-imagegen-source.png`: preserved built-in ImageGen source output.
- `../replica-app/app/src/main/res/drawable-nodpi/irl_streamer_logo_foreground_v2.png`: padded adaptive-icon foreground used by Android.

## Generation record

Mode: built-in ImageGen, followed by local alpha cleanup and Android-safe sizing.

Final source prompt:

> Create one original, minimal symbol for IRL Streamer, a professional mobile live-broadcast control app. Fuse a camera aperture, a forward-moving route, and a broadcast signal into one centered, recognizable silhouette. Use cool cyan, signal mint, and a small off-white accent. No text, initials, camera body, shield, pin, enclosing tile, watermark, mockup, or 3D treatment.
