# IRL Streamer identity

The mark combines a camera aperture, broadcast signal, and forward route to represent mobile live production.

## Files

- `irl-streamer-mark-v2.png`: transparent project mark.
- `irl-streamer-app-icon-v3.png`: 1024 × 1024 launcher/store preview from the current icon set.
- `../replica-app/app/src/main/res/mipmap-*/ic_launcher_foreground.png`: adaptive launcher foreground layers used by Android.
